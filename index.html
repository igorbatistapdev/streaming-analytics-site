Sobre o Projeto

Plataformas de streaming geram uma quantidade enorme de registros de uso. Este projeto transforma esses registros em respostas.

Contexto

O consumo de conteúdo digital no Brasil se divide entre plataformas, categorias e horários. Entender esse comportamento ajuda a comparar o desempenho de cada serviço.

Objetivo

Aplicar análise e visualização de dados com Python para identificar padrões de consumo, comparar plataformas e apresentar os resultados de forma interativa.

Problema analisado

Como consumo, assinaturas, receita e avaliações se distribuem entre plataformas, tipos de conteúdo e períodos?

Por que importa

Indicadores claros e visualizações bem escolhidas transformam dados brutos em decisões sobre catálogo, audiência e receita. A base utilizada é simulada, de uso acadêmico.
